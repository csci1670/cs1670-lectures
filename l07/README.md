# Lecture 7 code

This repository contains two versions of the code for lecture 7:
 - `v01` sets up timer interrupts in a simplified form, i.e., with as
   little code as is reasonable.  Start here first.
 - `v02` contains a more generic implementation, which can handle
   multiple types of interrupts, and callback function passed to the
   timer.  This version most closely matches the handout and lecture;
   look here after viewing v01.
